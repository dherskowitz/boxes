## Reserved names

Nuxt flattens `composables/`, `utils/` and `queries/**` into one namespace and resolves a duplicate **silently** — one wins, the other is dropped. That produced a real defect in v1 that only `pnpm typecheck` caught.

Every taken name is in `docs/superpowers/interface-surface.md`. On top of those:

| Slice | May export | Components |
|---|---|---|
| **I** | changes to `itemFilter` / `useItemList` signatures only — no new top-level exports expected | `Item*` |
| **D** | no new query exports; it consumes `useBoxFill`, `useTagUsage`, `useGrowth`, `reportTotals`, `topBoxesByItems` | `Dashboard*` |

Need a name outside this? **Stop and report.**

## Binding on both

- **`assertOnline()` first in every write mutation.** Mutations run `networkMode: 'always'` so it executes.
- **Never interpolate into a PocketBase filter string** — `$pb.filter(raw, params)`.
- **`useAuth()` is setup-only**; `useAuthUser()` is safe in handlers.
- **Every `UAlert` needs a semantic `color`.** All 38 in the app have one; a new one without it renders an error in the primary colour, which is green.
- **Every form uses `UForm` with a validate function.** No silent failures.
- Barebones styling: Nuxt UI defaults, layout primitives only, no colour classes, no custom CSS. A tag chip in its stored `color` via inline `:style` is data and is fine.
- Four distinct states where they apply: loading, empty, no-matches, error.

### Testing rules earned the hard way

All in `CLAUDE.md` and the interface surface. The ones that bite:

- The e2e suite runs `workers: 1`. Do not change it.
- `describe.configure({ mode: 'serial' })` orders one file only — never mutate a seeded record; create what you write to.
- Teardown goes in `test.afterEach`, never a `finally` — Playwright hard-kills a timed-out test.
- Call `pb.autoCancellation(false)` on a test's PocketBase client.
- **Never assert an absolute count on a global aggregate.** Derive expected numbers from the API at assertion time.
- Run `pnpm nuxt prepare` before `pnpm typecheck` after any branch switch.

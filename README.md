# Storage Boxes

Mobile-first PWA for tracking items in physical storage boxes, each with a printable QR code.

See [docs/storage-app-prd.md](docs/storage-app-prd.md) and [docs/pocketbase-schema.md](docs/pocketbase-schema.md).

## Development

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
pnpm preview
```
